# TDR-0008 — Security testing + pen-test + static/dep/secret scanning

**Status:** Accepted · **Version:** 1.0 · **Owner:** QA/Eng Lead · **Date:** 2026-07-04

## Context
Security must be verified continuously (SDR-0012), not only at review time; a PHI platform needs external
validation before go-live.

## Decision
**CI-blocking:** SAST, DAST, dependency scanning, secrets scanning, container + IaC scanning, plus authz/
authn negative tests and RLS tests (TDR-0006). **External penetration test before production go-live** and
after major changes; criticals gate release. Security review required for authz/RLS/crypto/secrets/infra.

## Alternatives Considered
- **Scans as non-blocking warnings** — ignored over time. Rejected (blocking).
- **No external pen-test** — insufficient assurance for PHI. Rejected.

## Trade-offs
Gates + pen-test add time/cost; essential for a healthcare security posture.

## Consequences
Vulnerabilities caught in CI; independent assurance before go-live.

## Dependencies
SDR-0012, IDR-0011, TDR-0006/0012.

## Confidence
High. ## Reversibility Medium.

## Phase Classification
Structural Foundation (CI scans) + Production (pen-test cadence).

## Related Documents
TESTING-ARCHITECTURE §12/§13/§25/§26.

## Review Trigger
New threat; compliance/audit requirement.
