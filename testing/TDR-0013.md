# TDR-0013 — Test data management (synthetic, no PHI)

**Status:** Accepted · **Version:** 1.0 · **Owner:** QA/Eng Lead · **Date:** 2026-07-04

## Context
Using real PHI outside production is a breach and a DPDP violation (SDR-0004/0010). Tests still need
realistic data.

## Decision
**No real PHI in any non-prod environment or test.** Use **synthetic/anonymized** generators producing
India-realistic data (ABHA-shaped ids, names, coded values from `reference`). **Tenant fixtures (A/B)** for
isolation tests; deterministic seeds; sensitive fields use fake-but-valid formats; per-suite create/teardown;
no cross-tenant leakage in fixtures.

## Alternatives Considered
- **Masked prod data in staging** — re-identification risk; still PHI-derived. Rejected for MVP.
- **Ad hoc hand-made data** — inconsistent, unrealistic. Rejected (generators).

## Trade-offs
Building good synthetic generators is effort; eliminates PHI exposure and improves reproducibility.

## Consequences
Realistic testing with zero PHI outside prod; reproducible, isolation-ready fixtures.

## Dependencies
SDR-0004/0010, DDR 0012 (code systems), TDR-0006.

High. ## Reversibility Low.
