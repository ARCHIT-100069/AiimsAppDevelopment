# TDR-0003 — Integration + DB testing (real Postgres + RLS, Testcontainers)

**Status:** Accepted · **Version:** 1.0 · **Owner:** QA/Eng Lead · **Date:** 2026-07-04

## Context
Tenant-context transactions, RLS, outbox atomicity, and concurrency (DDR 0002/0007/0009) can only be
verified against a real Postgres with the app role.

## Decision
Integration tests run application-service + repository against **real PostgreSQL via Testcontainers**, as
the **`aiims_app` role** (FORCE RLS as in prod). Cover tenant-context, outbox+audit atomicity, optimistic
concurrency, and worker idempotency/tenant-context. DB tests cover migrations (expand/contract + rollback),
constraints/enums/exclusion, index presence, and **RLS policy presence** (removal fails CI).

## Alternatives Considered
- **Mocked DB / SQLite** — doesn't exercise Postgres RLS/features. Rejected.
- **Shared long-lived test DB** — state bleed, flakiness. Rejected (ephemeral containers).

## Trade-offs
Container spin-up is slower than mocks; the fidelity is essential for a PHI/RLS system.

## Consequences
High-fidelity verification of the data + isolation layer.

## Dependencies
DDR 0002/0007/0009/0011, TDR-0006, IDR-0011.
