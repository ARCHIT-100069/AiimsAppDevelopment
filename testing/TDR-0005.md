# TDR-0005 — E2E + component testing (Playwright/Detox, OPD flow)

**Status:** Accepted · **Version:** 1.0 · **Owner:** QA/Eng Lead · **Date:** 2026-07-04

## Context
The critical clinical journey must be verified end-to-end on web and mobile (FEDR-0014), without a slow,
brittle E2E-heavy suite.

## Decision
**Playwright (web) + Detox/Maestro (mobile)** cover the **OPD hero flow** against a seeded staging-like env
with synthetic data and per-role test users. **Component tests** (RTL/RN) with a11y assertions cover UI
units; shared headless hooks tested once. Visual-regression for the design system. E2E kept few/high-value.

## Alternatives Considered
- **E2E for everything** — slow/flaky. Rejected (few, high-value).
- **No mobile E2E** — leaves native flows unverified. Rejected.

## Trade-offs
E2E is slower and needs stable envs; the OPD flow is worth guarding directly.

## Consequences
The revenue/clinical-critical journey is protected on both platforms.

## Dependencies
FEDR-0014, Roadmap (OPD), TDR-0010, IDR-0002.

High. ## Reversibility Medium.
