# ODR-0007 — Production deployment procedures + rollback

**Status:** Accepted · **Version:** 1.0 · **Owner:** SRE/Ops Lead · **Date:** 2026-07-04

## Context
A 24/7 clinical system requires zero-downtime deploys and fast, deterministic rollback (IDR-0015, DDR-0011).

## Decision
**Canary blue/green (CodeDeploy):** deploy to a slice → **bake + watch SLIs** → progressive shift → 100%,
with **automated rollback on alarm**. **Expand/contract DB migrations** run ahead of code (always backward-
compatible). Pre/post-deploy smoke tests (TDR-0011). **Rollback = redeploy prior image digest**; feature-flag
kill-switch for instant disable; every release ships with a documented rollback path.

## Alternatives Considered
- **In-place/recreate deploys** — downtime; unacceptable clinically. Rejected.
- **Destructive one-step migrations** — unsafe rollback. Rejected (expand/contract).

## Trade-offs
Canary + expand/contract add steps/latency to releases; deliver zero-downtime safety.

## Consequences
Safe, observable, reversible production deploys with no clinical downtime.

## Dependencies
IDR-0015, DDR-0011, TDR-0011, ODR-0006.

## Confidence
High. ## Reversibility Medium.
