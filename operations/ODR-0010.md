# ODR-0010 — Security operations (SecOps)

**Status:** Accepted · **Version:** 1.0 · **Owner:** SRE/Ops Lead + Security Architect · **Date:** 2026-07-04

## Context
Security is continuous, not a one-time review; the frozen controls (SDR-0008/0012) must be operated and
maintained in production.

## Decision
**Continuous SecOps:** GuardDuty/CloudTrail/Config monitoring; **vulnerability triage + patch SLAs**;
dependency/image CVE response; **key/secret rotation operations** (KMS/Secrets Manager); WAF tuning;
**least-privilege access reviews**. Security alerts route to on-call + Security Architect (ODR-0004); threat
detection feeds incident response (ODR-0003).

## Alternatives Considered
- **Point-in-time security only** — posture decays; new CVEs unaddressed. Rejected.
- **No rotation ops** — stale keys/secrets accumulate risk. Rejected.

## Trade-offs
Ongoing SecOps toil (mitigated by automation); maintains the security posture over time.

## Consequences
Living security posture; timely patching/rotation; fast threat response.

## Dependencies
SDR-0008/0012, ODR-0003/0004, IDR-0010.
