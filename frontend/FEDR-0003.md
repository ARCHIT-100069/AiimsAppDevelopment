# FEDR-0003 — Cross-platform code sharing (shared packages + platform UI)

**Status:** Accepted · **Version:** 1.0 · **Owner:** Frontend Lead · **Date:** 2026-07-04

## Context
Web and mobile must stay consistent and avoid duplicated business/UX logic, while each renders natively.

## Decision
Share **`domain-types`, `api-contracts` (typed client), `validation` (Zod), `design-tokens`, and
framework-agnostic hooks/logic** across web + mobile. Keep **platform-specific UI** in `ui-web` (shadcn/ui)
and `ui-native` (RN) implementing the same design system. Dependencies flow inward to `domain-types`.

## Alternatives Considered
- **Fully separate web/mobile codebases** — drift + duplicated logic. Rejected.
- **One UI library for both (react-native-web everywhere)** — compromises native fidelity. Rejected in
  favor of shared logic + platform-native UI.

## Trade-offs
A shared/native split needs disciplined package boundaries; delivers consistency + native quality.

## Consequences
Identical behavior/validation cross-platform; only rendering differs; single source of contracts.

## Dependencies
