# ADR 0008 — Identity: buy (Keycloak), don't build

**Status:** Proposed · **Date:** 2026-07-03 · **Confidence:** Medium-High
**Phase classification (ADR 0010):** Structural Foundation (OIDC seam + in-app authorization model) +
MVP Implementation (Keycloak with basic login/roles). MFA, enterprise SSO federation, and production
identity verification are Production Implementations; ABAC/break-glass is Future.

## Context
Master Ch. 6 lists JWT, OAuth 2.0, OIDC, MFA, and enterprise SSO as capabilities — presented as if
to implement. Building and maintaining an identity provider for healthcare (session security, MFA,
SSO federation, token lifecycle, account recovery, audit) is a large, security-critical surface and a
poor use of a two-founder team's time. It is not a differentiator.

## Decision
Adopt a proven identity provider rather than building one:
- **Recommended: Keycloak** (self-hosted in `ap-south-1`) — OIDC/OAuth2/SAML, MFA, SSO federation,
  no per-MAU cost, data stays in-region, healthcare-friendly.
- Alternative: **AWS Cognito** if the team prefers fully-managed and accepts its customization limits.
- AIIMS+ consumes the IdP via OIDC; **RBAC/authorization stays in the application** (roles scoped by
  user, role, department, organization, resource — per Ch. 6), because healthcare authorization is
  domain-specific and shouldn't live entirely in the IdP.

## Consequences
- (+) Removes a large security-critical build; faster path to MFA/SSO that enterprise hospitals demand.
- (+) In-region self-hosting (Keycloak) keeps identity data resident and cost flat as users grow.
- (−) Keycloak is an operational component to run, patch, and HA — real but far smaller than building
  an IdP. Cognito trades that ops burden for less flexibility and per-MAU cost.
- (−) Fine-grained clinical authorization still must be designed in-app (see a future authz ADR:
  RBAC now, evaluate ABAC/relationship-based access for break-glass and department scoping later).

## Reversibility
Medium — OIDC abstraction makes swapping IdPs feasible but not free.
