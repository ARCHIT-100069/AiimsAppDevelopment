# ADR 0006 — ABDM integration: isolated adapter, sequenced M1→M4

**Status:** Proposed · **Date:** 2026-07-03 · **Confidence:** High
**Phase classification (ADR 0010):** Structural Foundation (adapter interface) + MVP Implementation
(mock ABDM gateway returning fake ABHA IDs / consent artifacts, so the full link-and-share experience
is demoable). Real M1→M3 sandbox→prod certification is a Production Implementation; M4/NHCX is Future.

## Context
ABDM certification proceeds through milestones: **M1** identity (ABHA creation/verification/linking),
**M2** Health Information Provider (share FHIR records on consent), **M3** Health Information User +
consent management (fetch records; the most complex milestone), **M4** claims via NHCX. ABDM is an
external contract with its own sandbox → production sign-off lifecycle and periodic spec changes.

## Decision
Implement ABDM as an **isolated adapter module** with its own boundary, so its churn never leaks into
the core domain:
- The adapter owns ABDM gateway calls, the FHIR mapping layer (ADR 0003), consent-artifact exchange
  with the Consent Manager (ADR 0004), and encryption of shared bundles.
- The core domain speaks its own model; the adapter translates at the edge.
- **Sequence:** M1 (ABHA on-ramp) → M2 (become HIP) → M3 (HIU + consent-driven sharing) → M4 (NHCX).
- Sandbox and production configs are isolated; no sandbox credentials in the core.
- When ABDM load or release cadence justifies it, the adapter is the natural first module to extract
  into its own service (per ADR 0001).

## Consequences
- (+) ABDM spec/version changes are contained to one module.
- (+) Milestone sequencing matches NHA's own certification path and de-risks incrementally.
- (−) Requires ongoing conformance testing against NHA validators and sandbox.
- (−) M3 consent + encrypted FHIR flow is genuinely complex; budget 6–12 weeks incl. sandbox sign-off.

## Constitutional note
ABDM integration shares and ingests records; it performs **no** diagnosis or clinical inference.
Any AI applied to ingested records stays within the operational-AI boundary (Master Ch. 19).
