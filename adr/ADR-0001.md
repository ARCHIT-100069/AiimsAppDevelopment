# ADR 0001 — Deployment topology: modular monolith on ECS Fargate

**Status:** Proposed · **Date:** 2026-07-03 · **Confidence:** High
**Phase classification (ADR 0010):** Structural Foundation + MVP Implementation — the modular monolith
on Fargate *is* the MVP topology. Service extraction is a Future Enhancement gated on real load.

## Context
Master Ch. 6 lists Kubernetes, microservices, and event-driven messaging as the architecture,
softened with "where justified." Read literally, this pushes a two-founder team toward distributed
systems on day one. The original intent — "build once, scale forever," support thousands of
hospitals — is correct. The proposed *mechanism* (K8s + microservices now) is not, for a team that
cannot yet staff SRE, platform, and on-call for a fleet of services.

## Decision
Ship a **modular monolith**: NestJS with hard module boundaries (each bounded context is a module
exposing an explicit public interface; no cross-module reaching into internals). One Aurora
PostgreSQL cluster. Redis for cache/queues. Deploy containers on **AWS ECS Fargate** — not EKS.
Inter-module communication is in-process via a typed event bus backed by a **transactional outbox**,
so event contracts exist from day one and survive a later split.

Extract a module into its own service only when it has a *specific* proven need (independent scaling,
isolation, or language boundary) — e.g. imaging, notifications, the ABDM adapter (ADR 0006), the
Python AI plane.

## Consequences
- (+) Operable by a small team; one deploy, one DB, one trace context.
- (+) Bounded contexts + outbox mean the monolith→services split is mechanical later, not a rewrite.
- (+) Lower cost and latency than premature microservices.
- (−) Requires discipline to keep module boundaries honest (enforce via lint rules / import boundaries).
- (−) A single deploy unit means a bad deploy affects everything — mitigated by CI gates, canary on
  Fargate, and feature flags.

## Alternatives considered
- **Microservices + EKS now:** rejected — operational burden unstaffable; premature.
- **Serverless-first (Lambda):** rejected for the core transactional system — cold starts, connection
  management to Postgres, and long-lived clinical workflows fit poorly; fine for isolated async jobs.

## Reversibility
Medium. The monolith is designed to be split; the outbox and module boundaries are the hedge.
