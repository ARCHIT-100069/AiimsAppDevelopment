# IDR-0003 — VPC, networking & security groups

**Status:** Accepted · **Version:** 1.0 · **Owner:** Cloud & Infra Architect · **Date:** 2026-07-04

## Context
PHI data stores must be unreachable from the internet; network must be least-privilege and observable
(SDR-0008).

## Decision
Per-env VPC across **≥2 AZs** (3 in prod) with three subnet tiers: **public** (ALB/NAT only), **private
app** (Fargate tasks), **isolated data** (Aurora/Redis, **no internet route**). **Default-deny security
groups**, tier-to-tier least-privilege only. **VPC endpoints** (S3/ECR/Secrets/KMS/CloudWatch) keep AWS
traffic private. WAF/Shield at the edge; flow logs to the security account. External AI egress allow-listed.

## Alternatives Considered
- **Flat/2-tier network with public DB + SG rules** — larger attack surface. Rejected.
- **Single AZ** — no HA. Rejected.

## Trade-offs
Three tiers + endpoints add setup/cost; strongly reduce blast radius and data exposure.

## Consequences
Data stores are private; traffic is least-privilege and logged.

SDR-0008, IDR-0004/0006/0007/0009.
