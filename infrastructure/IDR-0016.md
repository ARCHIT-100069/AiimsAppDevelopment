# IDR-0016 — Local development environment (Docker Compose parity substrate)

**Status:** Accepted · **Version:** 1.0 · **Owner:** Cloud & Infra Architect · **Date:** 2026-07-05

## Context

The frozen phases define the AWS substrate (IDR-0002…0010) and Testcontainers for automated tests
(TDR-0003/0014), but no phase specified how a developer *runs* the full application locally —
identified as a documentation gap at Stage 0 kickoff. Founder decision (2026-07-05): Docker Compose
with PostgreSQL, Redis, Keycloak, and MinIO.

## Decision

- **Docker Compose** is the canonical local development substrate — local seams mirror the frozen
  AWS services one-to-one: **PostgreSQL 16** ↔ Aurora (IDR-0006), **Redis 7** ↔ ElastiCache
  (IDR-0007), **Keycloak** (dev realm auto-imported, `tenant_id` claim mapper, synthetic users
  matching the DB seed) ↔ Keycloak on Fargate (ADR-0008), **MinIO** ↔ S3 (IDR-0008; idle until a
  stage needs object storage). Only provider endpoints change between local and AWS — never code.
- **Synthetic data only** (TDR-0013); all compose credentials are local-dev defaults, and real
  secrets never enter the repo (SDR-0006). `.env` is gitignored; `.env.example` documents every
  Zod-validated variable (BDR-0011).
- **Developer-workstation gates mirror CI** (SDR-0012 shift-left): Husky pre-commit runs
  lint-staged (ESLint incl. BDR-0013 boundaries + Prettier) and commitlint enforces Conventional
  Commits (Master Plan §26). CI remains the authoritative gate.
- **Toolchain pins:** Node 22 LTS (`.nvmrc`, `engines`), pnpm via `packageManager`. Non-Docker
  container runtimes (colima) are supported via `DOCKER_HOST`/`~/.testcontainers.properties`.

## Alternatives Considered

- **Testcontainers-only (no compose)** — covers tests but not an interactively runnable stack
  (Keycloak login, manual demos). Rejected as the sole mechanism.
- **Native services via Homebrew** — drifts from container parity and is unreproducible across
  machines. Rejected.
- **Shared cloud dev environment** — cost, latency, and PHI-adjacency risk for day-1 development;
  deferred until team growth demands it.

## Trade-offs

Compose duplicates a little service definition (vs Terraform), and MinIO/Keycloak local behavior
can differ from AWS/managed equivalents at the margins. Accepted: identical seams + adapter
boundaries mean divergence surfaces as config, not code.

## Consequences

A new machine reaches a running, login-able, fully gated stack with four commands; the isolation
gate and policy-diff check run against the same Postgres engine version as CI.
