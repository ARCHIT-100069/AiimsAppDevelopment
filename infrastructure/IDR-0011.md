# IDR-0011 — CI/CD (GitHub Actions, OIDC, gates) + web/mobile pipelines

**Status:** Accepted · **Version:** 1.0 · **Owner:** Cloud & Infra Architect · **Date:** 2026-07-04

## Context
Delivery must be automated, secure, and gated by the safety controls defined across phases (SDR-0012,
isolation gate, AI eval gate).

## Decision
**GitHub Actions** with **OIDC-federated short-lived AWS creds** (no long-lived keys). Pipeline gates
(merge/deploy-blocking): lint → typecheck → unit → **integration (RLS)** → **cross-tenant isolation gate** →
**AI safety/eval gate** → SAST/dep/secret/container/IaC scans → build → ECR → env-gated deploy. Protected
branches + required reviews; **security review** for authz/RLS/crypto/secrets/infra. Separate **web
(container)** and **mobile (EAS build)** pipelines (IDR-0015/§27).

## Alternatives Considered
- **Jenkins/self-hosted CI** — ops burden. Rejected.
- **Long-lived cloud keys in CI** — leak risk. Rejected (OIDC).
- **Optional/non-blocking gates** — regressions slip through. Rejected (blocking).

## Trade-offs
Strict gates slow some merges; that is the safety property for a PHI system.

## Consequences
Secure, automated, safety-gated delivery for backend, web, and mobile.

## Dependencies
SDR-0012, DB §17 (isolation gate), AIDR-0012 (eval gate), IDR-0005/0012.
