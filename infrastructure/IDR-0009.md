# IDR-0009 — ALB load balancing + Route 53 DNS + ACM + WAF

**Status:** Accepted · **Version:** 1.0 · **Owner:** Cloud & Infra Architect · **Date:** 2026-07-04

## Context
Traffic must be TLS-terminated, WAF-protected, routed to Fargate services, and support zero-downtime
deploys and DR failover.

## Decision
**Application Load Balancer** per env (ACM TLS, WAF, health checks) routing to Fargate; supports **blue/green
+ canary** target groups (IDR-0015). **Route 53** hosted zones (shared-services) with per-env subdomains and
**health-check failover records** for DR (IDR-0014); private hosted zones for internal DNS. SSE works over
ALB HTTP; WebSockets deferred.

## Alternatives Considered
- **NLB for HTTP app** — ALB's L7 routing/WAF/target-group shifting fits better. Rejected for the app tier.
- **Third-party DNS** — Route 53 integrates with ACM/failover/health checks. Preferred.

## Trade-offs
ALB adds per-LCU cost; provides L7 routing, WAF, and safe deploys.

## Consequences
Secure, observable ingress with zero-downtime deploys and DNS-level DR failover.

## Dependencies
SDR-0008, IDR-0003/0014/0015, APDR-0009 (SSE).
