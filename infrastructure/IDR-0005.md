# IDR-0005 — Container & Docker standards + ECR

**Status:** Accepted · **Version:** 1.0 · **Owner:** Cloud & Infra Architect · **Date:** 2026-07-04

## Context
Containers are the deploy artifact; they must be secure, minimal, reproducible, and scannable (SDR-0012).

## Decision
**One immutable image per service**, tagged by git SHA, in **ECR** (scan-on-push). **Multi-stage builds**,
**minimal/distroless base** (pinned digest), **non-root**, read-only root FS where feasible, no secrets in
images. **SBOM + image scanning** in CI; **signing/provenance** (cosign/SLSA) in Production. Build once →
promote the same image across envs.

## Alternatives Considered
- **Fat images / latest tags** — larger attack surface, non-reproducible. Rejected.
- **Per-env rebuilds** — drift risk. Rejected (promote one artifact).

## Trade-offs
Multi-stage/distroless adds build complexity; yields small, secure, reproducible images.

## Consequences
Secure, traceable artifacts; rollback = redeploy a prior digest.

## Dependencies
SDR-0012, IDR-0011.

High. ## Reversibility Medium.
