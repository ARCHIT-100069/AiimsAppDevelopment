# APDR-0010 — Outbound webhooks (signed), Production

**Status:** Accepted · **Version:** 1.0 · **Owner:** API/Backend Lead · **Date:** 2026-07-04

## Context
Tenant systems will want to subscribe to domain events (e.g. `encounter.finalized`). Internal events already
flow via the outbox (BDR-0005); external delivery needs its own contract.

## Decision
**Signed outbound webhooks (Production):** per-tenant subscriptions to domain events, **HMAC-signed**,
retried with backoff, delivered from workers, **no PHI in payloads** (references + minimal fields, SDR-0004).
Authorized + audited. MVP ships the event model; external delivery is behind a feature flag (ADR 0010).

## Alternatives Considered
- **Push PHI in webhook payloads** — leak risk to third parties. Rejected (references only).
- **No webhooks (polling only)** — poor integration DX. Deferred, not rejected.

## Trade-offs
Webhook delivery infra (signing, retries, dead-letter, subscription mgmt) is real work; deferred to Production.

## Consequences
Integration-friendly event delivery without PHI exposure; internal events unaffected.

## Dependencies
BDR-0005, ADR 0010, SDR-0004.

## Confidence
High. ## Reversibility Medium.

## Phase Classification
Production Implementation.
