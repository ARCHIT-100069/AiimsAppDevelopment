# SDR-0008 — Network & infrastructure security

**Status:** Accepted · **Version:** 1.0 · **Owner:** Security Architect · **Date:** 2026-07-04

## Context
PHI data stores must be unreachable from the public internet and infrastructure changes must be reviewable.

## Decision
- **VPC segmentation:** public subnets (ALB/WAF only), private (services), isolated data subnets
  (Aurora/Redis) with **no public route**; default-deny security groups; egress via NAT.
- **WAF** (OWASP + rate rules) + **Shield Standard**; **TLS everywhere**; internal mTLS optional (prod).
- **Terraform** IaC scanned (tfsec/checkov); least-privilege IAM; CloudTrail + GuardDuty; immutable minimal
  images; no SSH to Fargate tasks; env isolation (dev/staging/prod).

## Alternatives Considered
- Flat network / public DB with SG rules — larger attack surface. Rejected.
- ClickOps infra — unreviewable, drift-prone. Rejected.

## Trade-offs
Segmentation + IaC discipline add setup effort; strongly reduces blast radius and drift.

## Consequences
Data stores are private; infra changes are reviewed and scanned; strong perimeter + internal controls.

## Dependencies
ADR 0001/0007, SDR-0012 (IaC scanning).

## Confidence
High.

## Reversibility
Medium.

## Phase Classification
